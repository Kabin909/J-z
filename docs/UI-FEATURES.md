# J&Z Panel UI feature map

J&Z Panel provides an original dark/orange infrastructure interface rather than copying Pterodactyl's visual design.

## User workspace

- Overview / dashboard
- Server inventory
- Server lifecycle controls
- Realtime console surface
- File manager surface
- Backups
- Databases
- Network / allocations
- Activity / audit view
- Account preferences

## Administration

- Nodes / Wings fabric
- Users
- Eggs
- Domains
- Plugins
- Security center
- Settings

## Design

- Responsive desktop/tablet/mobile layout
- Orange J&Z visual identity
- Glass panels and telemetry cards
- Status badges and health indicators
- Command terminal
- Search/filter controls
- Explicit destructive-operation controls

The UI calls the project's existing API endpoints where they exist. Features that require an endpoint not present in the backend remain clearly represented as empty/configuration states instead of fabricating data.
