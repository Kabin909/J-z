# J&Z VPS Guide — Panel + Remote Wings

## 1. Panel VPS

On Debian/Ubuntu or another supported Linux distribution:

```bash
sudo bash <(curl -fsSL https://raw.githubusercontent.com/Kabin909/J-Z-Test/main/installer/install.sh)
```

The installer now bootstraps the repository if it was not cloned first.

Choose:

```text
2) Install Panel
```

For the combined local node, choose:

```text
1) Install Panel + Wings
```

## 2. Remote Wings VPS

On the Linux node:

```bash
sudo bash <(curl -fsSL https://raw.githubusercontent.com/Kabin909/J-Z-Test/main/installer/install.sh)
```

Choose:

```text
3) Install Wings
```

Enter the panel URL, node ID and node secret generated by the J&Z administration flow.

## 3. DNS

Point the panel hostname to the panel VPS:

```text
panel.example.com -> PANEL_IP
```

The node does not need to use the panel hostname. Its address should be the Wings HTTPS endpoint, for example:

```text
https://node01.example.com:8080
```

For production, put Wings behind TLS/reverse proxy and firewall the Wings port so only the panel/API network can reach it.

## 4. Verify

Panel:

```bash
curl -fsS http://127.0.0.1:4000/api/health
```

Wings:

```bash
curl -fsS http://127.0.0.1:8080/health
systemctl status jz-wings --no-pager
```

Diagnostics:

```bash
sudo bash installer/install.sh
# choose 6
```
